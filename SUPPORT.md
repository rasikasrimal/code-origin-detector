# Support

Need help with Code Origin Detector? Start here.

## Self-Service

- Consult `README.md` for installation and quickstart steps.
- Explore the structured guides in `docs/` for architecture, operations, and troubleshooting.
- Search existing issues and discussions on GitHub.

## Community Channels

- **Issues:** For bugs or feature requests, open a ticket using the appropriate template.
- **Discussions:** Use GitHub Discussions (coming soon) for questions or idea sharing.

## Direct Contact

- Email `support@code-origin-detector.org` for commercial or enterprise inquiries.
- Security concerns should follow the process in `SECURITY.md`.

## Service-Level Expectations

- Community support is provided on a best-effort basis.
- Maintainers aim to triage new issues within five business days.

We appreciate detailed reports—it helps us resolve problems faster.
