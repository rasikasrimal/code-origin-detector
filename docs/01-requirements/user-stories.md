# User Stories

## Security Analyst

- As a security analyst, I want to run the detector on a suspicious commit so that I can gauge whether AI assistance was used without disclosure.
- As a security analyst, I want a confidence score and rationale so that I can decide whether to escalate to manual review.

## Engineering Manager

- As an engineering manager, I want scheduled reports on repository activity so that I can monitor policy compliance.
- As an engineering manager, I want integration hooks for CI so that checks can run automatically on pull requests.

## Researcher

- As a researcher, I want to plug in a new stylometry feature so that I can test detection hypotheses.
- As a researcher, I want to export evaluation metrics by repository group so that I can compare performance across domains.

## Developer Advocate

- As a developer advocate, I want demo datasets and copyable examples so that I can show how the detector works at events.
- As a developer advocate, I want the frontend to simulate different heuristic weights so that I can demonstrate interpretability.

## Contributor

- As a contributor, I want clear coding guidelines so that I can submit patches confidently.
- As a contributor, I want automated tests and linting so that I can validate changes before opening a PR.
