# Communication Plan

## Channels

- **GitHub Issues & PRs:** Primary channel for roadmap, bug tracking, and code reviews.
- **Monthly Sync Call:** Cross-functional update with maintainers, researchers, and design (recorded and archived).
- **Async Updates:** Bi-weekly written status in `docs/00-overview/project-plan.md`.
- **Security Hotline:** Confidential email `security@code-origin-detector.org`.

## Cadence

| Stakeholder Group | Frequency | Format |
|-------------------|-----------|--------|
| Core Maintainers  | Weekly    | Stand-up call + action items |
| Contributors      | Bi-weekly | GitHub Discussions summary |
| Advisors          | Monthly   | Highlight report + roadmap checkpoint |

## Decision Logging

- Use GitHub Discussions for ADR-style records.
- Important architectural decisions should also be captured in `docs/02-design/system-architecture.md`.

## Feedback Loop

- Collect frontend usability feedback via issue template form.
- Invite beta partners to submit anonymised datasets; track onboarding friction in `support@` inbox.

## Tools

- GitHub Projects for kanban tracking.
- Shared calendar for release milestones.
- Slack bridge (if available) mirrored back to GitHub for archival transparency.
