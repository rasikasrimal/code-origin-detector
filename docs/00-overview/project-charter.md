# Project Charter

## Mission

Deliver a trustworthy toolkit that estimates whether source code was produced by a human or generated by AI systems. The project balances interpretability with accuracy so teams can make informed decisions about provenance-sensitive code.

## Objectives

- Build a modular detection pipeline spanning heuristics, stylometry features, and statistical models.
- Provide an accessible CLI and dashboard for demonstrations and validation.
- Curate benchmark datasets of human-authored and AI-generated code.
- Maintain rigorous documentation that allows researchers to reproduce and extend the work.

## Scope

- **In Scope:** Python and JavaScript support, feature extraction pipelines, model orchestration, CLI tooling, frontend demo, structured documentation, dataset scripts.
- **Out of Scope:** Enforcement workflows, policy decisions, legal guidance, or definitive authorship adjudication.

## Stakeholders

- **Core maintainers:** coordinate roadmap, reviews, and releases.
- **Researchers:** evaluate detection quality and propose new features.
- **Security & compliance teams:** assess risk of AI-generated code in critical systems.
- **Community contributors:** extend heuristics, models, and UI integrations.

## Success Metrics

- >85% macro F1 on curated validation benchmarks.
- Positive feedback from beta partners on interpretability and usability.
- Reduced triage time for suspicious code contributions compared to manual review.

## Constraints and Assumptions

- Detection reliability varies by language and code complexity.
- Training data for AI-generated code must be refreshed as model capabilities evolve.
- The system must remain transparent to avoid misuse as an automatic compliance gate.
